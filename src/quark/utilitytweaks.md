# 实用改进

夸克最讨喜的部分：一批「用过就回不去」的生活质量优化。

## 界面增强

- **箱子搜索（Chest Searching）**：按 `G`（默认键位，可在按键设置中修改）搜索所有已打开过的容器内容，找东西再也不用翻箱倒柜
- **物品栏整理（Inventory Sorting）**：一键整理背包与箱子
- **自动补货（Automatic Tool Restock）**：工具用坏时自动从箱子里补一把同款
- **快捷栏切换（Hotbar Changer）**：快速切换多组快捷栏
- **使用计数（Usage Ticker）**：在物品图标旁显示剩余耐久或数量
- **改进提示框（Improved Tooltips）**：物品提示显示附魔颜色、食物饱食度等增强信息
- **地图清洗（Map Washing）**：复制出的地图可洗成空白重新利用

## 操作优化

- **右键收割（Simple Harvest）**：右键成熟作物直接收割并自动补种
- **锄头收割（Hoe Harvesting）**：锄头右键一扫一大片成熟作物
- **跨位放置（Reacharound Placing）**：站在悬崖边可以「探身」把方块放到脚下的边缘上
- **锁旋转放置（Lock Rotation）**：按住按键放置方块可以锁定朝向
- **双开门联动（Double Door Opening）**：双开门会一起开关
- **发射器放置方块（Dispensers Place Blocks）**：发射器可以发射并放置方块
- **活塞推动方块实体（Pistons Move Tile Entities）**：活塞可以直接推箱子、刷怪笼等带数据的方块

## 探索便利

- **指南针全维度可用（Compasses Work Everywhere）**：指南针在下界和末地也能指向重生点
- **信标重定向（Beacon Redirection）**：信标光柱可以用染色玻璃变色
- **鞘翅指示（Elytra Indicator）**：屏幕显示鞘翅剩余耐久
- **自动行走（Auto Walk Keybind）**：绑定一个按键开启自动前进
- **返回按钮（Back Button）**：界面里的返回上一屏快捷键

## 杂项

- **种子袋（Seed Pouch）**：把种子统一装进小袋，播种更省事
- **镐头回收（Pickarang）**：回旋镖式工具，扔出去挖方块再飞回来
- **村民重铸（Villager Rerolling Rework）**：调整村民交易的刷新机制
- **更多村民（More Villagers）**：新增职业村民与对应交易
- **表情动作（Emotes）**：聊天框输入指令做出挥手等动作
- **物品分享（Item Sharing）**：聊天中分享手中的物品链接
- **微合成助手（Microcrafting Helper）**：合成单个木板等微量配方时不再需要摆满整个格子
- **玻璃碎片（Glass Shard）**：打碎玻璃掉落碎片，可再合成玻璃——手滑不再心疼
