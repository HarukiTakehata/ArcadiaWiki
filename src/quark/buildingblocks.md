# 建造方块

夸克为建筑师提供了海量原版风格的新建材，全部遵循原版纹理语言。

## 新石种与世界石材

- **新石种（New Stone Types）**：石灰岩、碧玉、板岩、云母等多种新石头，各自拥有磨制、砖块、台阶楼梯全套变体
- **石簇（Stone Clusters）**：世界各处生成的卵石与石块簇，采集即得对应石材
- **坚固深板岩（Sturdy Stone）**：无法被爆炸破坏的深板岩变体
- **灵魂沙岩 / 幽冥石（Soul Sandstone / Duskbound）**：下界主题的砂岩与黑蓝砖建材
- **压缩方块（Compressed Blocks）**：压缩碳、甘蔗块等九合一存储方块

## 木材变种

- **竖直木板（Vertical Planks）**：所有原版木板的竖纹版本——建筑立面终于不用横条纹了
- **原木树干（Hollow Logs）**：挖空的原木，内部可以塞雪、苔藓、梯子甚至种花
- **原木倒伏（Fallen Logs）**：森林地表随机生成的可采集倒木
- **樱花树与花木（Blossom Trees）**：多种颜色的花树生成于世界各地，提供彩色木材
- **书架变种（Variant Bookshelves）**：附魔台用的书架支持全部木材种类

## 屋顶与墙面

- **瓦片（Shingles）**：多种颜色的屋顶瓦片，搭出真正的坡屋顶
- **茅草（Thatch）**：稻草材质的廉价屋顶方块
- **格栅（Grate）**：透光透水的金属/木质格板
- **金色栏杆 / 金属按钮（Gold Bars / Metal Buttons）**：细栏杆与铁金银铜三种按钮

## 玻璃与灯饰

- **镶框玻璃（Framed Glass）**：带边框的透明玻璃连接方块
- **染色玻璃变种**：更多玻璃装饰选择

## 其他实用方块

- **绳索（Rope）**：可堆叠垂降的绳索方块
- **铁梯（Iron Ladder）**：更坚固的铁质梯子
- **铁棒（Iron Rod）**：类似末地棒的伸缩推杆
- **蜡烛变体 / 灵魂蜡烛（Soul Candles）**：下界风味的照明
- **彩虹灯（Rainbow Lamps）**：循环变色的装饰灯
- **竹制与木质栅栏门变种**：栅栏门覆盖全部材料种类

> [!TIP]
> 建筑党推荐搭配整合包内的锦致装饰（Supplementaries）、设计装饰（Design n' Decor）与家具模组使用，风格可以无缝衔接。
