## 简介

**补充**是一个「原版魔改」风格的大杂烩模组，把社区里最经典的模组创意浓缩成一个包：从实用的绳索、风箱、保险箱，到装饰用的烛台、横旗、篱笆框架，应有尽有。它的设计原则是让每个方块都像原版一样自然。

整合包同时附带其官方附属 **SuppSquared（补充平方）**，增加了金属灯笼、牌板与染色麻布袋等内容。

## 与整合包内模组的联动

theArcadia 内置了 Create（机械动力），补充与其自动联动：

| 内容 | 说明 |
|:-----|:-----|
| **信息显示源** | 时钟方块、地球仪、布告栏、水晶显示屏可接到 Create 的显示信息板上展示数据 |
| **沙漏** | 可被机械手等装置翻转，用于定时红石电路 |
| **竹刺** | 浸药竹刺对经过实体产生效果的行为可与机械装置组合 |
| **礼物盒** | 礼物盒的收件人信息可被 Create 的属性过滤器识别 |

> 📖 更多特性请参阅 [MCMod 百科·锦致装饰](https://www.mcmod.cn/class/3555.html)
