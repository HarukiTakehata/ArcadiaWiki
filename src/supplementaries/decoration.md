# 装饰与建造

锦致装饰模组一半的魅力在装饰——从烛光氛围到建筑细节，让房子真正像「家」。

## 照明

- **加固火把（Sconce）**：可放置在地面或墙面的复古火把，有灵魂、荧光、末影、铜绿、下界黄铜五种变体
- **蜡烛烛台（Candle Holder）**：可手持的烛台；撒红石粉变红光，末影与夜视等特殊变体提供额外效果
- **金灯台（Candelabra）**：三头金属烛台，对它使用红石粉同样变色
- **石灯 / 深板岩灯 / 黑石灯 / 末地石灯**：右键开关的灯具
- **灯笼系列**：SuppSquared 增加铜灯笼、金灯笼、黄铜灯笼、绯红灯笼
- **荧光液（Lumisene）**：可染色的发光液体，倒在地上形成光斑，装瓶后可泼洒照明

## 旗帜与标牌

- **横旗（Flag）**：悬挂式布旗，16 色可选，随风飘动
- **路标（Way Sign）**：可写入目的地的指示牌
- **布告栏（Notice Board）**：可张贴地图或书本的展示方块
- **黑板（Blackboard）**：可用染料直接作画的黑板
- **龙盾徽旗帜图案**：为旗帜印上龙纹图案

## 家具与小物

- **物品架（Item Shelf）**：把物品摆在墙上展示
- **书堆（Book Pile）**：可堆叠的书本装饰
- **花箱（Flower Box）**：窗台上的小花箱
- **门垫（Doormat）**：可写字的门口地垫
- **帽架（Hat Stand）**：展示头盔与南瓜的立架
- **雕像（Statue）**：可穿戴装备的装饰雕像
- **地球仪（Globe）**：可旋转把玩的地球仪，墨绘版本更有年代感
- **笼子（Cage）**：关小动物的装饰笼
- **种植盆（Planter）**：带泥土的装饰盆栽容器
- **凳子（Stool）**：可以坐的凳子
- **彩旗（Bunting）**：节日气氛的三角串旗

## 建筑结构方块

- **木框架 / 粗灰泥篱笆（Timber Frame / Daub Frame）**：都铎风格建筑的核心——框架内可填充任意方块，交叉支架与篱笆支架组合出半木结构墙面
- **遮阳棚（Awning）**：屋檐下的彩色雨棚
- **藤条栅栏（Wicker Fence）**：低矮的园艺栅栏
- **石瓦 / 黑石瓦（Stone Tile）**：屋顶用瓦片建材
- **沙砾砖（Gravel Bricks）**：砂砾烧制的砖块；耙过的沙砾是它的平整变体
- **棋盘格方块（Checker Block）**：黑白棋盘格装饰面
- **金栏杆门 / 铁栏杆门（Gold/Iron Gate）**：细栏杆造型的门，视野通透
- **金门 / 铅门 / 下界合金门**：三种金属材质的门与活板门，越贵越坚固
- **篝火（Fire Pit）**：可烹饪的装饰篝火
- **灰烬砖（Ash Bricks）**：烧焦风格的深色砖块建材
