# 探索与地图

暮色森林地形复杂、结构众多，善用地图和随身小工具能让探险事半功倍。

## 三种魔法地图

三种地图都在**工作台**上合成，核心原料是各自的「地图核心」：

| 地图 | 功能 |
|:-----|:-----|
| **魔法地图** | 相当于升级版探索者地图：显示地形、生物群系，并标注各类建筑结构的位置 |
| **迷宫地图** | 进入迷宫类结构（牛头人迷宫等）后使用，揭示内部布局与宝藏位置 |
| **矿石地图** | 由迷宫地图加铁、金、钻石块升级而来，标记附近有价值矿物 |

核心的合成配方：

- **魔法地图核心 = 渡鸦羽毛 + 火炬浆果 + 荧石粉**

**迷宫地图核心**没有合成配方，只能从牛头人迷宫的战利品箱获取，牛头人也有几率掉落

> [!TIP]
> 渡鸦在暮色森林各地飞翔，火炬浆果生长在洞穴中——深入迷宫前先备好魔法地图，能省下大量探路时间。

## 实用小物件

- **保管符咒**：死亡时保留部分物品——探险前备一个能少跑很多冤枉路
- **生命符咒**：受到致命伤害时自动触发，救你一命
- **炽铁镐**：挖掘的方块会自动熔炼成对应产物（挖铁矿直接得铁锭）
- **玻璃剑**：一次性的超高伤害武器，适合对首领打爆发
- **孔雀羽扇**：推开身边的怪物，跳跃时还能把自己推向空中，配合鞘翅使用体验极佳
- **变化木船**：变化木制成的船——变化树能把周围区域转变为魔法森林，是获取魔法森林物产的移动平台
- **瓦解之号角**：粉碎附近的方块，开路神器
- **月光蠕虫**：丢出后会发光照明，比火把更隐蔽

## 暮色森林的天气

- 部分区域上空漂浮着**雨云和雪云**，可以采集放置，用来装饰或模拟天气效果

## 睡觉与重生

- 在暮色森林中睡觉会把重生点设在当地——长途探险时带上床，死亡后不必重新穿越半个维度
