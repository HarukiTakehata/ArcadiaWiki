# 物产与美食

暮色森林不只是战斗——这里出产大量独特食材。theArcadia 还内置了两个以暮色食材为主题的美食附属，把它们变成一桌好菜。

## 暮色特产食材

- **浆果莓丛**：暮色森林各地都能找到，直接采集食用
- **火炬浆果**：生长在洞穴里的发光浆果，可食用也可照明
- **九头蛇肉排**：击败九头蛇的奖励，食用后**完全填满饥饿值**，是顶级食物
- **野猪肉、鹿肉**：森林常见猎物的肉类，可用**晾干架**制成肉干保存
- **实验物品 115**：外形酷似蛋糕的神秘食物，在巨魔洞穴中能找到
- **极光蛋糕 / 冰川蛋糕**：冰雪区域特产制成的甜点

## Twilight Delight（暮色乐事）

以农夫乐事（Farmer's Delight）风格加工暮色食材：

- **炽铁锅**：自我供热、快速烹饪暮色菜肴的高级锅具
- **苍穹木橱柜 / 黑木橱柜**：配套的厨房储物方块
- **暮色菜肴**：炽汁蛇宴等用暮色食材烹制的大餐，提供远超基础食物的增益

## Kaleidoscope·暮色篇（万花筒）

用暮色特产酿造茶饮与果酒：

- **娜迦茶 / 火焰茶 / 热泪茶 / 冰晶茶**：以各首领区域的特产冲泡的茶饮
- **巨人烈酒 / 自然葡萄酒 / 蛇蜕利**：酿造的果酒类饮品
- **洞窟萤火酿 / 德鲁伊秘酿 / 巫术秘酿**：特殊风味的酿造物
- **暮色炉灶**：配套的酿造与烹饪方块
