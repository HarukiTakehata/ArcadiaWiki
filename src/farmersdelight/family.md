# 美食家族模组指南

theArcadia 内置了 9 个美食向模组。其中 6 个直接接入农夫乐事的**厨锅/砧板**配方体系，可以看作「农夫乐事大家族」；其余的各自成体系，也一并收录在本页。

| 模组 | 定位 | 与农夫乐事的关系 |
|:-----|:-----|:-----------------|
| **暮色乐事** | 暮色森林食材料理化 | 厨锅/砧板联动 |
| **乡村乐事** | 新作物与新家常菜 | 厨锅/砧板联动 |
| **饮酒作乐** | 酿酒与奶酪熟成 | 厨锅/砧板联动 |
| **森罗物语：厨房** | 茶饮、面食与自动化厨房 | 厨锅联动 + 自有机器 |
| **妖怪们的归家** | 东方 Project 弹幕与妖怪食材 | 厨锅/砧板联动（非官方移植版） |
| **异常乐事** | Abnormals 系模组的食物补充 | 厨锅/砧板联动 |
| **那不勒斯风味** | 冰淇淋与甜品体系 | 独立体系 |
| **Berry Good** | 浆果深加工 | 独立小体量 |
| **万花筒：暮色篇** | 暮色特产茶饮酒 | 独立体系 |

## 暮色乐事（Twilight Delight）

把[暮色森林](../twilightforest/index.md)的猎物和特产搬进农夫乐事的厨房：

- **炽铁锅**：以更快的速度烹饪暮色菜肴；**迷宫炉灶**则是另一台高速烹饪方块
- 暮色野味入菜：鹿肉肋排、熟牛头人肉片、熟战斧牛头人肋排、小炒肥虫等
- 特色宴席菜：炽汁蛇宴、暮光惠灵顿牛排、荷花鸡
- 冰雪甜品线：极光蛋糕、冰川蛋糕、极光冰淇淋、极光奶昔

## 乡村乐事（Rustic Delight）

为农场新增三类经济作物——**甜椒（绿/红/黄）、咖啡、棉花**：

- 甜椒可做甜椒汤、甜椒意面、三色寿司；野生甜椒在野外也能找到
- 咖啡豆烘焙后冲泡咖啡，还有巧克力咖啡这样的变体
- 棉花收棉铃纺布料；煎饼系列（蜂蜜/巧克力/南瓜煎饼）是早餐担当
- 鱿鱼类食材：生鱿鱼、鱿鱼寿司、烤鱿鱼片

## 饮酒作乐（Brewin' And Chewin'）

围绕**发酵桶**展开的酿酒与乳制品模组：

- **发酵桶**：把果汁、麦芽汁酿成啤酒、苹果酒、蜂蜜酒、康普茶、血腥玛丽等饮品
- **奶酪轮**：鲜奶酪放进桶里熟成，用小刀切成块——淡黄与绯红两种基底
- 火辣奶酪火锅、披萨、乳蛋饼等硬菜；腌鱼、泡菜、肉干等下酒小食
- 饮品自带特殊效果，宴会上人手一杯

## 森罗物语：厨房（Kaleidoscope Cookery）

自带一套「东方厨房」机器的料理模组：

- **茶壶、汤锅、石磨**等专属厨具，配合进度树逐步解锁
- 面食线：扯面等手工面点（连音效都叫「扯面声」）
- 配套的**森罗厨房：自动化**附属提供了流水线方案
- 另有 Ponder 支持包，手持物品按 W 可查看机器说明（与 Create 的思索界面同源）

## 妖怪们的归家（Youkai's Homecoming，非官方移植版）

东方 Project 主题模组：幻想乡的妖怪们带着弹幕战斗来到 Minecraft：

- 琪露诺、蕾米莉亚、博丽灵梦、雾雨魔理沙等角色会作为 NPC 出现
- 击败或讨好妖怪可获得特色食材与道具（投喂灵梦各种食物有惊喜掉落）
- 妖怪食材接入农夫乐事的厨锅/砧板体系，能做成独特的幻想乡料理
- 弹幕系统、青蛙帽子等趣味玩法自成一线

> [!NOTE]
> 整合包内置的是该模组的**非官方移植版**（Youkai's Homecoming Unofficial Port）。

## 异常乐事（Abnormals Delight）

为包内一众 Abnormals 系模组（Atmospheric、Environmental、Neapolitan 等）的食物做农夫乐事风格的补充，属于「缝合胶水」型小模组——装了它，热带作物的料理选择更多。

## 那不勒斯风味（Neapolitan）

独立甜品体系，主打三种风味原料：

- **香蕉**：香蕉树结果，可做香蕉面包、香蕉冰激凌、香蕉奶昔，还有香蕉箭这种整活道具
- **红豆**：红豆沙包、红豆咖喱、红豆煲
- **巧克力与薄荷**：巧克力砖可以当建材，薄荷派系有薄荷冰激凌
- 三种口味可以组合成**半半冰淇淋**之类的混合甜品

## Berry Good

小体量的浆果增强模组：甜浆果可以磨出**甜浆果籽**再加工成**甜浆果肉馅、甜浆果肉丸**，让浆果从零食变成一道菜；附带一张狐狸主题音乐唱片。

## 万花筒：暮色篇（Kaleidoscope Twilight）

见[暮色森林词条·物产与美食](../twilightforest/food.md)：娜迦茶、火焰茶、热泪茶、巨人烈酒等暮色特产茶饮。
