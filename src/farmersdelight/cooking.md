# 烹饪与营养

农夫乐事的料理不只是换个花样回饥饿值——它的核心价值在于两种专属状态效果：**滋养**与**舒适**。

## 滋养（Nourishment）与舒适（Comfort）

吃下丰盛的料理后，你会获得这两种增益：

- **滋养**：「你不会再消耗饥饿值，除非需要借以恢复生命值」——效果期间正常行走、挖掘、战斗都不掉饱食度，只有受伤回血才消耗。食物条上方会出现金色边框提示
- **舒适**：「使你对饥饿、缓慢和虚弱效果免疫」——探险时被蜘蛛咬、被女巫泼药都不怕。生命值条上方会有滚动特效提示

一盘大餐的增益可以持续很长时间，是下矿、远征前最值得准备的「行军粮」。

## 厨锅料理

厨锅是把多种原料炖成一碗的慢工细活：

- 需要下方有营火持续加热，锅里缺水会罢工
- 一次最多投入 6 种原料，产出按配方固定
- 代表菜谱：牛肉炖、鱼肉炖、洋葱汤、蔬菜汤、热可可、苹果酒
- 盛出需要碗，部分饮品用玻璃瓶

## 煎锅：现煎现吃

**煎锅**是拿在手里的烹饪工具：

- 手持煎锅对着营火放置的炉灶使用，把食材丢上去滋滋作响
- 适合处理肉片、鸡蛋等简单食材，比熔炉更快更有仪式感
- 在水里没法煎——游戏会提醒你「在水里可没法煎啊……」

## 砧板切割一览

砧板加工是许多配方的中间步骤，常见的有：

| 类别 | 例子 |
|:-----|:-----|
| 切肉 | 生猪排 → 生猪肉丝；生牛肉 → 生牛肉饼 |
| 切菜 | 卷心菜 → 卷心菜叶；南瓜 → 南瓜切片 |
| 制面 | 面团 → 生面条；面包 → 吐司×2 |
| 剥皮 | 稻米穗脱粒等 |

切割需要对应的工具（多为小刀），工具会被嵌在砧板上方便连续作业。

## 与整合包工厂衔接

theArcadia 里农夫乐事自带了与 Create 的联动配方：

- **碾磨机**可以把小麦磨成面粉等（8 条碾压配方）
- **混合器**能完成部分搅拌类工序（3 条混合配方）
- 大批量生产面粉、面团时交给流水线，手工厨房只负责最后的炖煮
