# 烹饪与营养

农夫乐事的料理不只是换个花样回饥饿值——它的核心价值在于两种专属状态效果：**滋养**与**舒适**。

## 滋养（Nourishment）与舒适（Comfort）

吃下丰盛的料理后，你会获得这两种增益：

- **滋养**：「你不会再消耗饥饿值，除非需要借以恢复生命值」——效果期间正常行走、挖掘、战斗都不掉饱食度，只有受伤回血才消耗。食物条上方会出现金色边框提示
- **舒适**：「使你对饥饿、缓慢和虚弱效果免疫」——探险时被蜘蛛咬、被女巫泼药都不怕。生命值条上方会有滚动特效提示

一盘大餐的增益可以持续很长时间，是下矿、远征前最值得准备的「行军粮」。

## 厨锅料理

厨锅是把多种原料炖成一碗的慢工细活：

- 需要下方有热源持续加热（营火是最常用的选择）
- 一次最多投入 6 种原料，产出按配方固定；锅的界面自带配方书，照着列表投料即可
- 代表菜谱：蔬菜汤（胡萝卜 + 马铃薯 + 甜菜根 + 叶菜）、牛肉炖、鱼肉炖、洋葱汤、热可可、苹果酒
- 盛出需要碗，部分饮品用玻璃瓶

## 煎锅：现煎现吃

**煎锅**是拿在手里的烹饪工具：

- 放在**炉灶**或营火上方，手持食材右键投料，滋滋作响；烹饪完成后成品自动弹出
- 适合处理肉片、鸡蛋等简单食材，比熔炉更有仪式感
- 在水里没法煎——游戏会提醒你「在水里可没法煎啊……」

## 砧板切割一览

砧板加工是许多配方的中间步骤，常见的有：

| 类别 | 例子 |
|:-----|:-----|
| 切肉 | 生猪排 → **培根**×2；牛肉 → **牛肉馅**×2 |
| 切鱼 | 鳕鱼、鲑鱼 → **生鱼片**×2，附赠骨粉 |
| 切菜 | 卷心菜 → **卷心菜叶**×2；南瓜 → **南瓜片**×4 |
| 制面 | 面团 → **生意面** |

切割需要对应的工具（多为小刀），工具会被嵌在砧板上方便连续作业；蛋糕和馅饼的分块也要靠砧板完成。

## 与整合包工厂衔接

theArcadia 里农夫乐事自带了与 Create 的联动配方：

- **混合器**能完成部分搅拌类工序：卷心菜直接搅出卷心菜叶，番茄加碗搅出番茄酱，再用面粉和牛奶混出馅饼酥皮
- **碾磨机**适合处理野生作物，能把挖回来的野生作物磨出种子和染料
- **注液器**还能往馅饼酥皮里注入巧克力，一步做出整只巧克力派
- 大批量备料交给流水线，手工厨房只负责最后的炖煮和摆盘
